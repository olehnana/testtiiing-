# 📰 Шинковий Вісник — Посібник із переносу та запуску на Raspberry Pi 5

Цей проєкт — стилізований під вінтажну газету сайт бару українською мовою з базою даних SQLite, каталогом напоїв (без цінників), миттєвим пошуком та адмін-панеллю для перемикання наявності позицій в один клік.

## 🚀 Крок 1: Як перенести проєкт з ПК на Raspberry Pi 5

Оберіть один із трьох найзручніших способів:

### Спосіб А: Через WinSCP (Найпростіший візуальний спосіб)
1. Завантажте безкоштовну програму **[WinSCP](https://winscp.net/)** на Windows ПК.
2. Вкажіть IP-адресу вашої Raspberry Pi 5, логін (`pi` або ваш) та пароль.
3. Просто перетягніть папку `bar` з вашого ПК у домашню директорію на Raspberry Pi (`/home/pi/bar`).

### Спосіб Б: Через PowerShell за допомогою однієї команди SCP
Відкрийте PowerShell на вашому ПК у папці `d:\` та виконайте:
```powershell
scp -r d:\bar pi@<IP_АДРЕСА_RASPBERRY_PI>:/home/pi/bar
```

### Спосіб В: Через GitHub
1. Створіть репозиторій на GitHub та надішліть туди код з ПК:
   ```bash
   git init
   git add .
   git commit -m "Initial bar newspaper"
   git remote add origin <URL_ВАШОГО_РЕПОЗИТОРІЮ>
   git push -u origin main
   ```
2. На Raspberry Pi просто клонуйте його:
   ```bash
   git clone <URL_ВАШОГО_РЕПОЗИТОРІЮ> /home/pi/bar
   ```

## ⚙ Крок 2: Запуск автоматичного налаштування на Raspberry Pi 5

Підключіться до вашої Raspberry Pi по SSH або відкрийте термінал безпосередньо на платі й виконайте:

```bash
cd /home/pi/bar
chmod +x deploy/pi_setup.sh
./deploy/pi_setup.sh
```

Цей скрипт автоматично:
- Встановить Python 3, `pip` та `venv`.
- Створить віртуальне середовище й встановить Flask та Gunicorn.
- Ініціалізує базу даних `bar.db`.
- Створить і запустить системний сервіс `bar.service` — сайт працюватиме у фоні та **автоматично вмикатиметься разом із живленням плати**!

## 🌐 Крок 3: Підключення Cloudflare Tunnel (Публікація в Інтернет)

Щоб сайт відкривався зі смартфонів гостей через інтернет без відкриття портів у роутері:

1. Встановіть `cloudflared` на Raspberry Pi 5:
   ```bash
   curl -L --output cloudflared.deb https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-arm64.deb
   sudo dpkg -i cloudflared.deb
   ```
2. **Швидкий запуск без власного домену**:
   ```bash
   cloudflared tunnel --url http://localhost:8000
   ```
   Вам буде видано публічне посилання `https://*.trycloudflare.com`.

3. **Постійний запуск із власним доменом**: детальні інструкції дивіться у файлі [deploy/cloudflared_setup.md](file:///d:/bar/deploy/cloudflared_setup.md).

## 🍸 Крок 4: Керування прейскурантом (Адмінка)

- Адреса входу: `http://<IP_МАЛИНКИ>:8000/admin` або `https://ваш-домен/admin`
- **Пароль**: задається через змінну оточення `ADMIN_PASSWORD` (за замовчуванням `bar123`).
- **Перемикання наявності**: достатньо натиснути велику кнопку біля потрібного напою:
  - `[ ✓ Є В НАЯВНОСТІ ]` — позиція доступна, відображається із зеленим штампом.
  - `[ ✕ РОЗПРОДАНО ]` — на картці на головній сторінці миттєво з'являється ретро-штамп «ТИМЧАСОВО РОЗПРОДАНО».
- **Зміна тексту оголошення**: нагорі адмінки можна вписати новину дня або змінити години роботи закладу.
